# Wolf Security Tools

Security software developed by Abdullah Gülşen.

**Wolf Sentinel** monitors the behavior of AI agents. The goal is to detect agents that have been manipulated, taken over or never registered, as well as coordinated attacks by many agents, and to restrict only the agent that is causing the problem.

**Wolf Audit** scans source code and dependencies. The goal is to find signs of backdoors, data exfiltration and supply chain attacks before the code is used.

Both tools are still in development. They have not been released, the source code is closed, and they have not been independently audited yet. Performance figures will only be published after independent verification.
